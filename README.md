# 🐈‍⬛ KuroCat Pet（小黑猫桌面打字伴侣）

轻量级 Windows 透明置顶小黑猫桌宠，基于 **Tauri v2 (Rust + HTML5 Canvas 2D)** 打造，全局同步你的真实键盘打字与鼠标操作。

## ✨ 核心特性

- **纯黑手绘风小黑猫**：荧光黄绿大眼睛（实时眼球追踪 + 随机自然眨眼）、会摇摆的尾巴、细白手绘轮廓线与胡须。
- **抚摸互动**：把鼠标移到小黑猫头顶/身上轻轻来回抚摸，它会舒服地眯起黄绿月牙横线眼（即使开启鼠标穿透锁也能摸到）。
- **双爪实时 IK 精准敲键**：自带微俯视 65% 白灰机械键盘（橙黄 ESC 与方向键点缀）+ 左侧白色小鼠标；每个虚拟键码精确映射到对应键帽位置，打字时双爪平滑弹性伸展精准落键，高速打字自带动态残影。
- **实时悬浮 3D 按键气泡**：打字时在键盘上方弹出圆角立体白底键帽提示，自动防重叠并柔和淡出（右键或托盘可随时一键关闭）。
- **智能鼠标穿透**：透明背景自动穿透不遮挡正常办公/游戏；移到猫身上自动可拖动、抚摸、右键调设置，也可一键“彻底锁定穿透”。
- **超轻量 & 系统托盘**：单文件 `.exe` 仅数 MB，不占任务栏，支持自由缩放（75%–150%）、位置记忆、开机自启与可选轻脆键盘/呼噜音效。

## 🛠️ 本地开发与构建

前置要求：Windows 10/11、Node.js 18+、Rust 工具链（`cargo`）。

```bash
npm install
npm run tauri:dev      # 本地热更新调试
npm run tauri:build    # 编译 Release 可执行文件与 Windows 安装包
```

生成的独立绿色版可执行文件位于 `src-tauri/target/release/kuro-cat-pet.exe`，安装包位于 `src-tauri/target/release/bundle/`。
