# 🐈‍⬛ KuroCat

轻量级 Windows 透明置顶桌面打字猫咪伴侣（内置**经典小黑猫** & **蓝双布偶猫**一键切换），基于 **Tauri v2（Rust Win32 全局钩子 + HTML5 Canvas 2D）** 打造。单文件仅约 **3.2 MB**，常驻内存 ~24 MB，CPU 占用极低。

## ✨ 核心特性

- **双猫咪外观一键切换**：
  - **🐈‍⬛ 经典小黑猫**：饱满梨形坐姿身体、圆润猫耳、沉稳低垂 S 形小尾巴、柠檬黄绿大眼与荧光绿高亮键帽。
  - **🐱 蓝双布偶猫**：奶油雪白蓬松毛发 + 经典蓝灰正八字开脸与蓬松蓝灰大尾、淡粉内耳与粉嫩小鼻、带双高光的星光宝石蓝大眼、雪白手套猫爪与天蓝高亮键帽，右键或托盘 0.1 秒无缝切换。
- **摸头眯眼与呼噜互动**：把鼠标移到猫头上自动切换为黑白描边小手光标，来回抚摸即触发慵懒舒服的一字微垂细眯眼表情，并伴随轻柔拟真的猫咪呼噜声（默认开启，可随时在右键/托盘开关，不干扰自身键盘与鼠标声音）。
- **左右半区精准敲键 + 清晰字符键盘**：
  - 65% 白灰机械键盘印有清晰数字（`1–0`）与字母（`Q–P` / `A–L` / `Z–M`）标识，配橙色 `Tab` 与方向键点缀，真实按键按下同步亮荧光绿。
  - **左半区**（`Esc`、`1–6`、`Q–T`、`A–G`、`Z–B`）由左侧猫爪按压，**右半区**（`7–0`、`Y–P`、`H–L`、`N–M` 等）由右侧猫爪按压，纯打字时头部与上身随敲击节奏灵动左右晃动歪头，未敲键一侧自动蜷爪收在胸前。
  - 实时晃动/点击鼠标时自动切入**三联动**：左手牢牢抓鼠滑动并随点击亮荧光绿、身体按柔性脊柱自然斜向前探、右手兼顾键盘按压、眼球 100% 紧盯光标。
- **错落弹跳 3D 按键气泡**：键盘上方实时弹出白底立体键帽（含宽空格凹槽图标），支持右键/托盘一键开关（输密码更安心）。
- **智能鼠标穿透 & 系统托盘**：透明区域自动点击穿透不遮挡办公或游戏，移到猫身上可摸头、拖拽记位置、右键开设置（75%–150% 缩放、彻底锁定穿透、摸头呼噜声开关、始终置顶、开机自启）。

## 📥 直接下载使用（Windows 10 / 11）

前往 [Releases](https://github.com/qianyiai/kurocat/releases) 页面下载最新的免安装绿色版 `KuroCatPet-v3.0.0-windows-x64.exe`（约 3.2 MB），双击即可运行，右键猫咪或右下角系统托盘图标可随时切换「小黑猫 / 布偶猫」外观及各项设置。

## 🛠️ 本地源码构建

前置环境：Windows 10/11、Node.js 18+、Rust 工具链（`cargo`）。

```bash
git clone https://github.com/qianyiai/kurocat.git
cd kurocat
npm install
npm run tauri:dev      # 本地热更新调试
npm run tauri:build    # 编译 Release 可执行文件与安装包
```
